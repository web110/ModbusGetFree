## Языки

Язык по умолчанию — **английский**. Меню **Language** перед меню справки позволяет выбрать английский, упрощённый китайский, испанский, французский, русский, португальский, польский, японский, немецкий или корейский. Выбор сохраняется для следующего запуска.

## Запуск и сборка

Запустите `ModbusGetFree.exe`. Для сборки выполните `./build.ps1` в PowerShell с компилятором Windows .NET Framework. Исходный код C# находится в `src`.

## Возможности

- Последовательное соединение RTU, независимые окна данных и демонстрационное ведомое устройство без оборудования.
- Периодический опрос FC01/02/03/04 и операции FC05/06/15/16/17/22/23.
- Ручная отправка ожидает завершения текущей транзакции и приостанавливает новые опросы общего порта. После ответа, ошибки или тайм-аута опрос возобновляется. Таймер продолжает работать, пропущенные опросы не накапливаются. Широковещательная запись не ожидает ответа.
- Запись катушек и регистров, маски AND/OR, совместное чтение и запись, редактирование с учётом типа данных.
- Форматы отображения, масштабирование, шрифты, цвета, графики, запись трафика и тестовый центр.
- Документы `.mpdoc`, рабочие пространства `.mprtu`, импорт совместимых архивов `.mbp` V7.x/V9.x.

## Тесты и документация

`./test-ui-regression.ps1` проверяет интерфейс и языки; `./test.ps1` включает тесты RTU. Тесты используют демонстрационное устройство и не записывают данные в оборудование. Справка встроена в приложение. Подробности об ограничениях импорта, ресурсах и тестах см. в [английском README](README.md).
