Ce dossier contient l’application prête à utiliser. Téléchargez tout son contenu, conservez la structure et lancez `ModbusGetFree.exe`. Le dossier `assets` doit rester à côté du programme. Le code source et les tests ne sont pas nécessaires. Windows .NET Framework 4.5 ou ultérieur est requis.

L’interface propose 10 langues. L’anglais est la langue par défaut. Utilisez **Language** pour changer de langue ; le choix est enregistré.

Les mises à jour automatiques sont disponibles. Activez-les dans **Aide → À propos de ModbusGetFree** (désactivées par défaut). Une nouvelle version compatible propose une mise à jour immédiate, une mise à jour en arrière-plan (téléchargement maintenant, installation au prochain lancement ; choix limité à cette session), ou l’ignorance pour cette fois. En cas d’échec ou d’expiration du délai de connexion à GitHub, la prochaine tentative aura lieu au prochain lancement. La communication série reste inchangée.

Les mises à jour préservent les paramètres et documents. Le dossier du programme doit être accessible en écriture. Consultez la [documentation complète](../README.fr.md) et les [instructions de mise à jour](../UPDATES.md) (anglais/chinois).
