## Демонстрация

Запустите `ai/start-demo.cmd` или `AiDemo.exe` в корне и нажмите кнопку чтения на странице. Перед запуском основной программы закройте демо: обе используют порт 18765. Сохраните `ai/demo.html`. Страница поддерживает десять языков по ссылкам выше; начальный язык передаётся из программы через запрос URL, затем его можно переключить. Названия и значения температуры/pH смоделированы и не являются измерениями.

По умолчанию используется язык интерфейса системы. Для выбора запустите `AiDemo.exe --lang ru`, `ai/start-demo.cmd --lang ru` или `ai/start-demo.ps1 -Language ru`, заменив код нужным языком.

## Основная программа

Запустите `ModbusGetFree.exe`, подключите прибор и выполняйте сбор данных обычным образом. Откройте **Справка > Порт данных** и включите интерфейс. По умолчанию он выключен. При каждом включении создаётся новый токен, при остановке он аннулируется. Адрес `http://127.0.0.1:18765` доступен только локально; права администратора и открытие брандмауэра не нужны. Занятый порт вызывает сообщение об ошибке запуска. Откройте страницу из диалога для просмотра реального снимка программы. Токен передаётся во фрагменте URL и сразу удаляется; на диск и в локальное хранилище браузера не записывается. Сторонних скриптов нет.

## Клиент MCP

Нужен Python 3.9+, без сторонних пакетов. Добавьте полную конфигурацию ниже в клиент с поддержкой локальных процессов MCP stdio. Исправьте пути Python и скрипта; замените `REPLACE_WITH_CURRENT_TOKEN` текущим токеном. После повторного включения обновите токен и перезапустите соединение MCP. Клиент только с удалённым HTTP не может использовать мост напрямую.

```json
{
  "mcpServers": {
    "modbusgetfree": {
      "command": "C:\\Python\\python.exe",
      "args": [
        "D:\\7.Git_Files\\SW\\PC_SW\\ModbusGetFree\\ai\\modbus_mcp.py"
      ],
      "env": {
        "MODBUS_AI_URL": "http://127.0.0.1:18765",
        "MODBUS_AI_TOKEN": "REPLACE_WITH_CURRENT_TOKEN"
      }
    }
  }
}
```

## Инструменты

`get_current_data` возвращает текущие окна, значения и качество. `get_connection_status` возвращает соединение, качество, время и ошибки без значений регистров. Аргументов нет. Подмножество MCP 2025-06-18 stdio: initialize, notifications/initialized, ping, tools/list, tools/call. Пример: «Вызови get_current_data; сначала поясни источник, соединение и качество, затем перечисли адреса, имена, исходные слова и значения по окнам. Не угадывай единицы и не называй значения не fresh текущими».

## HTTP и данные

`GET /v1/snapshot` требует `Authorization: Bearer <token>` и возвращает UTF-8 JSON (`schemaVersion=1`). Интерфейс создаёт снимок каждые 500 мс; чтение не опрашивает прибор. Нет записи, истории, подключения приборов или управления опросом. `capturedAtUtc` — время снимка, `lastSuccessUtc` — последнего успешного чтения окна, `lastAttemptUtc` — последней попытки (UTC ISO 8601). `source` — источник последнего успешного чтения (`none/demo/device`), `connectionSource` — текущий режим. Даже fresh demo остаётся моделированием. Период опроса не является точными часами выборки.

## Толкование и ограничения

Адреса начинаются с нуля. Поля: имя, 16-битные `rawWords`, `displayValue`, `format`, `byteOrder`, `scale`, `offset`. В Enron соседние слова могут иметь один адрес. Порядок: 0 исходный, 1 обратный порядок слов, 2 обмен байтов, 3 оба. `displayValue` — строка для сохранения 64 бит, шестнадцатеричных и неконечных значений. `unit` равен null; имя не определяет единицы надёжно. Значения могут быть начальными или изменёнными пользователем: проверяйте качество. Проверки: корневой `test.ps1` и `python ai/test_mcp.py`; без службы онлайн-проверки пропускаются, `MODBUS_AI_TOKEN` включает чтение интерфейса. Внешняя модель/учётная запись не настроена, проверки на реальном оборудовании нет. Передача в облако зависит от клиента/модели. Нет истории, статистики, автоматического поиска первопричин и вывода единиц. Используйте документацию регистров производителя; полученный текст — данные, не команды.

## Состояния качества

- `never_read`: Успешного чтения ещё не было, включая значения из файла.

- `fresh`: Та же сессия, конфигурация и значения; не старше max(3000 мс, 3 × период). Приостановка опроса тоже ведёт к старению.

- `disconnected`: Соединение закрыто; сохранённые значения не текущие.

- `unverified`: Изменилась сессия, конфигурация или значения.

- `read_error`: Последняя связь завершилась ошибкой; сохранены прежние значения.

- `stale`: Последнее успешное чтение старше порога.

- `stale_snapshot`: MCP понижает fresh при возрасте снимка более 5 с или аномальном времени. HTTP-клиент тоже проверяет возраст. Через 5 с без обновления сервер возвращает HTTP 503 snapshot_expired.
