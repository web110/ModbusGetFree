Ten folder zawiera program gotowy do uruchomienia. Pobierz całą zawartość, zachowaj strukturę katalogów i uruchom `ModbusGetFree.exe`. Folder `assets` musi pozostać obok programu. Kod źródłowy i testy nie są potrzebne. Wymagany jest Windows .NET Framework 4.5 lub nowszy.

Interfejs obsługuje 10 języków. Domyślny jest angielski. Zmień język w menu **Language**; wybór zostanie zapisany.

Dostępne są automatyczne aktualizacje. Włącz je w **Pomoc → O ModbusGetFree** (domyślnie wyłączone). Nowa zgodna wersja umożliwia aktualizację teraz, pobranie w tle z instalacją przy następnym uruchomieniu (wybór tylko dla bieżącej sesji) lub pominięcie tym razem. Przy błędzie połączenia z GitHub lub przekroczeniu czasu kolejna próba nastąpi dopiero przy następnym uruchomieniu. Komunikacja szeregowa pozostaje bez zmian.

Ustawienia i dokumenty użytkownika zostają zachowane. Folder programu musi umożliwiać zapis. Zobacz [pełną dokumentację](../README.pl.md) i [instrukcje aktualizacji](../UPDATES.md) (angielski/chiński).
