Dieser Ordner enthält die sofort verwendbare Anwendung. Laden Sie den gesamten Inhalt herunter, behalten Sie die Ordnerstruktur bei und starten Sie `ModbusGetFree.exe`. Der Ordner `assets` muss neben der Programmdatei bleiben. Quellcode und Tests werden nicht benötigt. Windows .NET Framework 4.5 oder neuer ist erforderlich.

Die Oberfläche unterstützt 10 Sprachen. Englisch ist die Standardsprache. Wählen Sie die Sprache unter **Language**; die Auswahl wird gespeichert.

Automatische Updates sind verfügbar. Aktivieren Sie sie unter **Hilfe → Über ModbusGetFree** (standardmäßig aus). Bei einer neuen kompatiblen Version können Sie sofort aktualisieren, im Hintergrund herunterladen und beim nächsten Start anwenden (Auswahl nur für diese Sitzung) oder diesmal überspringen. Bei Verbindungsfehlern oder Zeitüberschreitungen zu GitHub erfolgt der nächste Versuch erst beim nächsten Programmstart. Die serielle Kommunikation bleibt unbeeinträchtigt.

Benutzereinstellungen und Dokumente bleiben erhalten. Der Programmordner muss beschreibbar sein. Siehe [vollständige Dokumentation](../README.de.md) und [Updateanleitung](../UPDATES.md) (Englisch/Chinesisch).
