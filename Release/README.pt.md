Esta pasta contém a aplicação pronta a utilizar. Transfira todo o conteúdo, mantenha a estrutura de pastas e execute `ModbusGetFree.exe`. A pasta `assets` deve ficar junto do executável. Não são necessários o código-fonte nem os testes. Requer Windows .NET Framework 4.5 ou posterior.

A interface suporta 10 idiomas. O idioma predefinido é inglês. Use **Language** para mudar; a seleção é guardada.

Existem atualizações automáticas. Ative-as em **Ajuda → Sobre o ModbusGetFree** (desativadas por predefinição). Uma nova versão compatível permite atualizar agora, transferir em segundo plano e aplicar no próximo arranque (escolha só para esta sessão), ou ignorar desta vez. Se a ligação ao GitHub falhar ou exceder o tempo limite, só haverá nova tentativa no próximo arranque. A comunicação série não é afetada.

Os ajustes e documentos são preservados. A pasta do programa deve permitir escrita. Consulte a [documentação completa](../README.pt.md) e as [instruções de atualização](../UPDATES.md) (inglês/chinês).
