本文件夹是可直接运行的软件。下载本文件夹的全部内容并保留目录结构，运行 `ModbusGetFree.exe` 即可。`assets` 文件夹必须与程序放在同一目录，无需下载源码和测试文件。需要 Windows .NET Framework 4.5 或更高版本。

界面支持英语、简体中文、西班牙语、法语、俄语、葡萄牙语、波兰语、日语、德语和韩语，默认英语。通过 **Language** 菜单切换，选择会自动保存。

软件支持自动升级。在 **帮助 → 关于 ModbusGetFree** 中打开“允许自动升级”开关（默认关闭），启动时检查新版。可选择**立即升级**、**后台升级**（后台下载，下次启动应用更新，选择仅本次有效）或**本次不升级**。连接 GitHub 失败或超时后，本次不重连、不重试，下次启动再尝试，不影响串口通信。

升级会保留用户设置和文档，程序目录需要可写权限。详见[完整说明](../README.zh-CN.md)和[升级说明](../UPDATES.md)。
