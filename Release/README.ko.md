# ModbusGetFree v1.10

[English](README.md) | [简体中文](README.zh-CN.md) | [Español](README.es.md) | [Français](README.fr.md) | [Русский](README.ru.md) | [Português](README.pt.md) | [Polski](README.pl.md) | [日本語](README.ja.md) | [Deutsch](README.de.md) | [한국어](README.ko.md)

이 폴더에는 바로 실행할 수 있는 프로그램이 들어 있습니다. 전체 내용을 다운로드하고 폴더 구조를 유지한 상태에서 `ModbusGetFree.exe`를 실행하세요. `assets` 폴더는 실행 파일과 같은 위치에 있어야 합니다. 소스 코드와 테스트 파일은 필요하지 않습니다. Windows .NET Framework 4.5 이상이 필요합니다.

화면은 10개 언어를 지원하며 기본값은 영어입니다. **Language** 메뉴에서 변경하면 선택이 저장됩니다.

자동 업데이트를 지원합니다. **도움말 → ModbusGetFree 정보**에서 업데이트를 허용하세요(기본값은 꺼짐). 호환되는 새 버전이 있으면 즉시 업데이트, 백그라운드 다운로드 후 다음 실행 시 적용(이번에만 유효한 선택), 이번에는 건너뛰기 중 선택할 수 있습니다. GitHub 연결 실패 또는 시간 초과 시 이번 실행 중에는 재시도하지 않고 다음 실행 시 다시 확인합니다. 직렬 통신에는 영향을 주지 않습니다.

업데이트 시 사용자 설정과 문서는 유지됩니다. 프로그램 폴더에 쓰기 권한이 필요합니다. [전체 설명](../README.ko.md)과 [업데이트 안내](../UPDATES.md)(영어/중국어)를 참고하세요.
