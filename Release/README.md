This folder contains the ready-to-run application. Download its complete contents, preserve the directory structure and run `ModbusGetFree.exe`. Keep the `assets` folder beside the executable. No source code or test files are needed. Requires Windows .NET Framework 4.5 or later.

The interface supports English, Simplified Chinese, Spanish, French, Russian, Portuguese, Polish, Japanese, German and Korean. English is the default. Choose **Language** to switch; the selection is saved.

Automatic upgrades are available. Enable **Allow updates: check GitHub at startup** under **Help → About ModbusGetFree** (off by default). A newer compatible release offers **Upgrade now**, **Upgrade in background** (download now, apply on next launch; session-only choice), or **Skip this time**. If GitHub cannot be reached or the check times out, there is no retry until the next launch. Serial communication is unaffected.

User settings and documents are preserved during upgrades. The application directory must be writable. See the [full documentation](../README.md) and [update instructions](../UPDATES.md).
