# ModbusGetFree v1.10 — Ready to run

Download this folder’s contents, keeping the directory structure, and run `ModbusGetFree.exe`. The `assets` folder must stay beside the program. Source code and test files are not required. Windows .NET Framework 4.5 or later is required.

Alternatively, download and extract `ModbusGetFree-update.zip` from the [latest release](https://github.com/web110/ModbusGetFree/releases/latest). Enable automatic upgrades in Help → About ModbusGetFree; the default is off.

仅使用软件时，下载本文件夹内容并保留目录结构，运行 `ModbusGetFree.exe` 即可。`assets` 文件夹必须与程序放在同一目录，不需要源码和测试文件。需要 Windows .NET Framework 4.5 或更高版本。也可以从[最新 Release](https://github.com/web110/ModbusGetFree/releases/latest)下载更新 ZIP 并完整解压。软件支持自动升级，可在帮助 → 关于中开启，默认关闭。
