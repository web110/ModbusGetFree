このフォルダーには実行可能なソフトウェアが含まれています。すべての内容をダウンロードし、フォルダー構成を維持して `ModbusGetFree.exe` を実行してください。`assets` フォルダーは実行ファイルと同じ場所に置きます。ソースコードとテストは不要です。Windows .NET Framework 4.5 以降が必要です。

画面は 10 言語に対応し、既定は英語です。**Language** メニューで切り替えると選択内容が保存されます。

自動更新機能があります。**ヘルプ → ModbusGetFree について** で更新を許可します（既定は無効）。対応する新しいバージョンがある場合、今すぐ更新、バックグラウンドでダウンロードして次回起動時に適用（今回のみの選択）、今回は更新しない、から選べます。GitHub 接続の失敗やタイムアウト時は今回の実行中に再試行せず、次回起動時に再確認します。シリアル通信には影響しません。

更新時もユーザー設定とドキュメントは保持されます。プログラムのフォルダーには書き込み権限が必要です。[詳しい説明](../README.ja.md)と[更新手順](../UPDATES.md)（英語・中国語）を参照してください。
