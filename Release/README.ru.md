В этой папке находится готовая к запуску программа. Скачайте всё содержимое, сохранив структуру папок, и запустите `ModbusGetFree.exe`. Папка `assets` должна находиться рядом с программой. Исходный код и тесты не нужны. Требуется Windows .NET Framework 4.5 или новее.

Интерфейс поддерживает 10 языков. По умолчанию используется английский. Выберите язык в меню **Language**; выбор сохраняется.

Поддерживается автоматическое обновление. Разрешите его в **Справка → О ModbusGetFree** (по умолчанию отключено). При наличии совместимой новой версии можно обновить сейчас, загрузить в фоне с установкой при следующем запуске (выбор только для текущего сеанса) или пропустить в этот раз. При ошибке соединения с GitHub или тайм-ауте повторная попытка выполняется только при следующем запуске. Последовательная связь не затрагивается.

Настройки и документы пользователя сохраняются. Папка программы должна быть доступна для записи. См. [полную документацию](../README.ru.md) и [инструкции по обновлению](../UPDATES.md) (английский/китайский).
