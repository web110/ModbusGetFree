Esta carpeta contiene el programa listo para usar. Descargue todo su contenido, conserve la estructura y ejecute `ModbusGetFree.exe`. Mantenga la carpeta `assets` junto al ejecutable. No necesita el código fuente ni las pruebas. Requiere Windows .NET Framework 4.5 o posterior.

La interfaz admite 10 idiomas. El predeterminado es inglés. Use **Language** para cambiarlo; la selección se guarda.

El programa admite actualizaciones automáticas. Active el permiso en **Ayuda → Acerca de ModbusGetFree** (desactivado por defecto). Si hay una versión compatible, puede actualizar ahora, actualizar en segundo plano (descargar ahora y aplicar al iniciar de nuevo; elección solo para esta sesión) u omitir esta vez. Si falla la conexión a GitHub o se agota el tiempo de espera, no se reintenta hasta el siguiente inicio. La comunicación serie no se ve afectada.

Las actualizaciones conservan los ajustes y documentos del usuario. La carpeta del programa debe permitir escritura. Consulte la [documentación completa](../README.es.md) y las [instrucciones de actualización](../UPDATES.md) (inglés/chino).
