# 外部 AI 只读数据接口第一版
用户已选择按需只读当前值与通信状态，并要求实现和演示。
采用现有 C#/.NET Framework，新增显式启停的本机 HTTP JSON 服务及 Python 标准库 MCP stdio 桥接。仅监听 127.0.0.1，随机会话令牌，不提供写入/连接/轮询控制。默认关闭，关闭程序停止服务。
UI 线程每 500ms 发布不可变快照，网络线程只读快照，不访问控件、不触发设备通信。
包含设备/功能码/协议地址/名称/原始值/显示值/格式/倍率、最近成功读取时间、最近尝试结果、连接与模拟来源。未读取、超时/断线、配置或原始值修改、连接会话变化均不能标为 fresh。过期阈值 max(3000ms, 3*扫描周期)。不推断单位。
附浏览器演示页、MCP 配置示例、操作说明。演示使用既有 RTU 模拟从站，明确标为模拟；不声称已接入云端模型或真实硬件。
其他方案：仅 CSV 无需新服务但不能交互查询；只做 MCP 耦合外部客户端。选择 HTTP + MCP 桥接以同时支持脚本和 AI 客户端。
验证：接口鉴权、GET 限制、跨源拒绝、停止释放端口、数据质量、分组转换、MCP 初始化与调用、现有回归。保留既有未提交修改，不自动提交或推送。
