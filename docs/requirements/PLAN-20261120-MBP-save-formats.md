# MBP 保存实施与验证计划

需求：REQ-20261120-MBP-save-formats.md；2026-11-20 用户授权“按照上面的改进”。

## 范围和实现
- 本次仅文档保存：保留 MPDOC，加入 v7/v9 二进制 MBP 和 v12 XML MBP。CSV/TXT/MBS/MBW 不纳入。
- 保存时记录来源格式版本及原始文档元数据；保留可复用的原文件记录，避免丢失未编辑字段。
- 由独立 MBP 文件模块负责读写和格式选择；DataWindow 保存入口使用同目录临时文件及替换，写入失败不破坏原文件，成功后才更新路径和格式。
- 未支持的功能、缩放或样式转换需明确拒绝或提示，不伪装已支持。

## 重点风险
- v7/v9 标签必须区分目标软件兼容与内部归档编号；不能仅凭名称宣称所有次版本兼容。
- 原始文件中未导入字段应保留；结构变化不能把旧数组错误搬到新地址或数量。
- XML 禁止外部实体，未知结构应明确报错。
- 多寄存器组不完整、不可表达样式或缩放不能静默保存。
- 目标应用验证与自有读写往返是两种不同证据。
