# REQ-20261106 MBP 寄存器地址排列对齐

用户要求：两软件打开同一文件时，起始寄存器显示必须一致，已授权修复。

原因：读取配置同为协议地址 2089，但本软件将其放在第 0 行并显示列头 02089；Modbus Poll 按固定 20 行地址块显示列头 02080，从第 9 行放入数据。

验收：HMT 列头 02080，前 9 行空白，pH 位于第 11 行（协议地址 2091）；跨列、编辑、粘贴和选中索引映射正确，空白区不能编辑；通信起始地址及数量保持 2089/10。保存并重新打开后保持对齐。

方案：为 MBP 导入状态增加可序列化的地址行对齐标记；固定行数时按协议地址取行偏移，列数包含前导空白；统一表格索引换算。普通既有文档沿用原有布局。

验证：先新增布局回归复现失败，再修复并运行专项及全套测试，最后检查实际界面。
