# MBP 原格式保存与另存为格式选择

- 编号：REQ-20261120-MBP-save-formats
- 提出日期：2026-11-20
- 状态：已实现、自动回归通过；待用户验收。v12 原版软件重开尚未验证。

## 背景和目标
用户要求：打开 .mbp 文件后，保存仍使用该格式；另存为可以选择 Modbus Poll 支持的格式，支持情况从官网核实。

## 使用场景
打开原有 Modbus Poll 文件，修改配置、名称、数据格式等后直接保存，继续在 Modbus Poll 中使用；另存为时选择目标格式。

## 修改前行为
- MainWindow.Files.cs：MBP 导入后清空 DocumentPath，当前为只读导入。
- DataWindow.Editing.cs：保存仅提供 .mpdoc，内容为本软件 DocumentState XML。
- MbpImporter.cs：仅识别二进制归档版本 7000/9000，FC03/04、1..125 个寄存器；部分样式未导入，启用缩放时拒绝导入。
- 既有需求记录的对标实测版本：Modbus Poll 9.2.2 Build 1343。不能由此推断已支持所有 MBP。

## 官网核实（2026-11-20）
- https://www.modbustools.com/ ：官网宣布 Modbus Poll 12 使用可读 XML 文件格式。
- https://www.modbustools.com/pollxml.html ：官方 XML 示例包含 ModbusPoll 根节点和 Version 12.0.0 Build 2444。
- https://www.modbustools.com/ModPollChangeLog.txt ：2025-10-02 Version 12.0.0 明确说明“*.mbp file format changed from binary to human readable XML format.”，确认 v12 XML 仍使用 .mbp 扩展名。
- https://www.modbustools.com/mbpoll-user-manual.html ：页面标注 2026-05-06；说明 .mbp 文档、.mbw 工作区、CSV（逗号或分号）、TXT（制表符）以及导出 Modbus Slave .mbs。
- .mbw 保存窗口布局和引用文件名，不包含实际文档内容；CSV/TXT 为名称和值导出，.mbs 为面向 Modbus Slave 的名称、值及格式导出。这些不能视为等价的可编辑文档格式。
- 官网格式说明不足以替代实际读写兼容验证；旧版可选保存版本仍需核实软件或进一步官方资料。

## 功能范围与界面行为
### 用户已提出
- 打开 .mbp 后直接保存仍为真正的 .mbp，不能把本软件 XML 改扩展名冒充。
- 另存为提供 Modbus Poll 支持的格式选择。

### 已确认实施范围
- 文档另存为保留 .mpdoc；用户进一步明确要求可选择 v7、v9、v12。三者均使用 .mbp，v12 为 XML；v7/v9 的具体兼容版本和内部结构对应仍需验证。
- CSV/TXT/MBS 导出、MBW 工作区兼容不纳入本次，原有功能保留。
- 原文件保存维持来源格式及版本；另存为文档成功后后续保存跟随新路径、格式。
- 无法表示的设置必须明确提示，不能静默丢失；失败或取消不能破坏原文件。

## 不包含的内容
- 未经确认不扩展到通信功能或数据类型变更。
- 不将数据导出文件当作完整文档，不承诺官网未说明的格式。
- 开发阶段不提交或发布；用户后续明确“上传发布”后授权发布 v1.11。

## 兼容性要求
- 按目标 Modbus Poll 版本记录类型、字节序、别名、数值、轮询和布局字段的支持矩阵。
- 对现有导入未覆盖的字段，实施前确定保留策略，避免覆盖保存破坏原文件。
- 兼容原有 .mpdoc/.mprtu；未知版本明确报错。

## 验收标准
1. 打开受支持 MBP、修改、保存，不要求转换为 MPDOC；文件可由目标版本 Modbus Poll 正确重开。
2. 对支持的全部数据类型及字节序建立覆盖测试，不仅验证单个样例。
3. 保存前后别名、数据、功能码、地址、数量、站号、周期和支持的显示设置一致；不支持设置明确提示或无损保留。
4. 另存为选择与实际编码、扩展名一致；后续保存跟随新文档路径。
5. 若纳入 CSV/TXT/MBS，验证导出内容、分隔符、转义和目标软件读取，且不改变当前文档保存目标。
6. 取消、无写权限、写入失败、未知格式时原文件完整。
7. 原有 MPDOC/MPRTU 打开保存回归通过。
