# ModbusGetFree v1.11

打开受支持的 MBP 文档后，“保存”保留原文件内部格式版本；“另存为”可选择 Modbus Poll v7、v9 或 v12 XML 格式，扩展名均为 `.mbp`。原有 `.mpdoc` 保存仍保留。

## 改进
- 保存成功后，后续保存跟随新路径和目标版本。
- 保留同版本源文件中的附加元数据，修正 XML 列宽、窗口位置等设置被重置的问题。
- 写入失败时保护原文件；对不能表达的设置明确报错，二进制/XML 互转时提示布局、日志等转换限制。
- 修正动态行数模式的读写，更新帮助和测试。

## 验证与兼容边界
- 完整回归 18 组通过，其中 MBP 保存测试 533 项；自动升级测试 82 项通过。
- 10 类数据类型、28 种格式/字节序组合及 HMT 混合类型样例覆盖三种输出格式。
- v7 已在官方 7.2.5、v9 已在官方 9.2.2 中重开验证。v12 XML 已在官方 13.2.1 中重开验证，尚未使用 v12 原版验证。
- MBP 读写当前限 FC03/04、1～125 个寄存器、站号 1～247、非 Enron。未知 XML 版本/结构和未支持的缩放等设置明确拒绝；高级样式不保证在本软件中显示或完整跨格式转换。
- 未进行探头、串口或硬件验证。

## 使用
下载 `ModbusGetFree-update.zip`，完整解压后运行 `ModbusGetFree.exe`，保留同目录的 `assets` 文件夹。需要 Windows .NET Framework 4.5 或更高版本。升级包不含用户设置或文档文件。
